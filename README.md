## Topic: Predicting First-Year Student Enrollment Yield Using Admissions Data at NC State

**Research Question:** Can we predict whether an admitted student will actually enroll based on their demographic, academic, financial aid characteristics, and which factors most strongly influence this decision at NC State?

- Scrape/obtain NC State course applicant info from the Common Dataset (https://report.isa.ncsu.edu/ir/cds/pdfs/CDS_2024-25.v3.pdf)

**Demographic Features:**

- Residency: In-state, Out-of-state, International (p14)
- Gender: Male, Female (p13)
- Race/Ethnicity: 8 categories (p6)
- First-generation status (p16)

**Academic Features:**

- High School GPA: Use distribution from page 21 (4.0, 3.75-3.99, etc.)
- SAT Composite: Use ranges from page 19
- ACT Composite: Use ranges from page 20
- Class Rank: Top 10%, Top 25%, etc.

**Application Features:**

- Application type: Early Action (11/1 deadline) vs Regular Decision (from page 23)
- Admission decision timing (from page 22)

**Financial Aid Features (pages 32-37):**

- Need-based aid eligibility (yes/no)
- Merit scholarship offered (yes/no)
- Financial aid package size (if applicable)

**Target Variable:**

- Enrolled (1) or Not Enrolled (0)
- Ground truth: Overall yield = 5,837 enrolled / 18,201 admitted = 32.1% (page 13)

## Instructions

1. Create a venv (recommended) and install all packages specified in `requirements.txt`
2. Run `dataset/synthesize_dataset.py` to create both the `ncstate_admissions_dataset.csv` and the `ncstate_data_dictionary.csv`
   - The admissions dataset contains the columns student_id,gender,residency,race_ethnicity,first_generation,high_school_gpa,gpa_category,class_rank,sat_composite,sat_submitted,act_composite,act_submitted,application_type,intended_major,applied_for_aid,has_financial_need,need_based_aid,receives_merit_scholarship,merit_scholarship,total_aid_package,enrolled,yield_probability
   - The dictionary set is meant as a summary for all the respective columns
3. Change directory to the `model/train` folder, and run the train files (`train_decision_tree.py`, `train_random_forest.py`, `train_svm.py`) independently
4. After getting output, change directory to the `model` folder, and run the `compare_models.py` file to compare the output generated by the .json files.
5. You can view all results in the `model/results` folder.
